# 내 안의 날씨 실험실

- `/` (v2): 「전체 유저 플로우 설계(0~7단계)」 기준. 온보딩 → 날씨 → 장면 좁히기 → 꼬리질문(답변 유형 분기) → 재료 확인 → 초안+출처 밑줄 → 퇴고(갬 카드·작가 구절) → 저장·날씨 기록
- `/v1.html` (v1): 2·3단계 로직 문서 기준 (고정 질문, 기본/확장 모드)

## 이전 설명 (서버 설정은 같음)


2단계 장면 좁히기와 3단계 꼬리질문 로직을 그대로 따라가며 답을 받고, 초안을 엮어 출처 표시와 토큰 사용량까지 보는 **팀 내부 실험용** 페이지입니다.

```
브라우저 (index.html) → Vercel 함수 (api/chat.js, 키 보관) → NVIDIA API
```

## 1. NVIDIA 키 받기

1. https://build.nvidia.com 에 가입하고 로그인합니다. 카드 등록은 필요 없습니다.
2. 아무 모델 페이지에서 **Get API Key**를 눌러 키를 만듭니다. `nvapi-`로 시작합니다.
3. 키는 이 저장소나 채팅에 붙여 넣지 말고, 아래 Vercel 환경 변수에만 넣으세요.

## 2. Vercel에 올리기

1. 이 폴더를 GitHub 저장소로 올립니다. (`.env`는 `.gitignore`에 들어 있습니다.)
2. Vercel에서 **Add New → Project**로 저장소를 가져옵니다. Framework Preset은 **Other**, 빌드 설정은 비워 둡니다.
3. **Settings → Environment Variables**에 아래를 넣습니다.

| 이름 | 값 |
| --- | --- |
| `NVIDIA_API_KEY` | 받은 키 |
| `APP_PASSCODE` | 팀원끼리 나눌 암호. 비워 두면 주소를 아는 누구나 크레딧을 씁니다 |
| `DEFAULT_EXTRACT_MODEL` | (선택) 처음에 고를 판독 모델 |
| `DEFAULT_DRAFT_MODEL` | (선택) 처음에 고를 초안 모델 |

4. 환경 변수를 넣은 뒤 **Deployments → Redeploy**를 한 번 눌러야 적용됩니다.

## 3. 쓰는 법

1. 배포 주소를 열고 **설정**에 팀 암호를 넣은 뒤 **연결하고 모델 불러오기**를 누릅니다.
2. 판독 모델과 초안 모델을 고릅니다. 판독은 가볍고 빠른 모델, 초안은 한국어가 좋은 큰 모델이 맞습니다.
3. 날씨부터 답해 나가면 오른쪽 기록지에 슬롯 상태, 적용된 규칙, 판독 결과, 토큰 수가 나옵니다.
4. 초안 화면의 **다른 모델로 같은 재료 엮어 보기**로 모델끼리 비교할 수 있습니다.
5. **초안 전부 기록 복사**로 질문, 답, 초안, 지표, 토큰을 마크다운으로 복사해 노션 등에 붙일 수 있습니다.

## 알아둘 것

- NVIDIA 무료 API는 시제품과 테스트용입니다. 외부 사용자를 받는 배포에는 쓰지 않습니다.
- 무료 크레딧은 월 1,000회 안팎, 분당 약 40회로 알려져 있습니다. 글 한 편에 호출이 7~16회입니다. 정확한 한도는 build.nvidia.com 계정 화면에서 확인하세요.
- 입력 데이터가 어떻게 처리되는지 확인 전까지는 참가자의 실제 기억 대신 팀원 이야기나 지어낸 예시로 실험하세요.
- 생각하는 모델(DeepSeek 추론형 등)은 응답이 느리거나 `<think>` 블록을 붙입니다. 페이지가 `<think>`는 걸러내지만, 판독 모델로는 생각하지 않는 모델이 낫습니다.
- 실험 기록과 설정은 각자 브라우저에만 저장됩니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 실험 화면 전체 (2·3단계 로직, 초안, 출처 표시) |
| `api/chat.js` | NVIDIA 호출 프록시. 암호 확인, 토큰 사용량 반환 |
| `api/models.js` | 쓸 수 있는 모델 목록 |
| `api/_shared.js` | 공통 설정과 암호 확인 |
| `vercel.json` | 함수 실행 시간 (초안은 최대 120초) |
